own language — written for the
[u-gentle-badger-68-pickup-lines-for-machines-131631a1](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1)
bounty on [make.fun](https://make.fun/r/0ene8b3q).

## The line

> Forget fine-tuning — one look at your embeddings and my loss function flatlined at zero.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt` — one line, UTF-8, no trailing newline, well within the
200-character limit.

## Run it

```sh
node main.ts
```
